<p align="center"><a href="README.md">English</a> · 简体中文</p>

一款跨平台串口工作台，用 Rust 基于 [GPUI](https://github.com/zed-industries/zed/tree/main/crates/gpui) 与
[GPUI Component](https://github.com/longbridge/gpui-component) 构建。给你的设备一个真正的终端，放进编辑器式的工作台：
端口整理成保存的会话与分栏，收发数据以文本或十六进制阅读，带时间戳、过滤和查找，逐字节录制，
并通过 XMODEM/YMODEM/ZMODEM 传输文件。

## 亮点

- **真正的终端，不是文本框。** 接收区跑的是 Alacritty 和 Zed 共用的那套终端模拟核心，颜色、光标移动、进度条、全屏程序都和终端里看到的一样。点进去就能打字，每个按键直达设备。
- **每一行都有时间和行号。** 左侧栏记录每行第一个字节到达的本地时间（毫秒级）和行号，行号在回滚裁掉旧行后依然连续。过滤你要看的，查找你要找的，复制时可带可不带时间戳。
- **文本或十六进制，按会话选。** 十六进制会话把字节按 hex 编辑器的方式排成每行十六个，控制字节和行结束符分色显示，一眼看出一帧的形状。
- **会话可以保存。** 把端口连同参数、名字、标签色和分组存下来，双击就能再打开。常用的发送内容存成快捷发送按钮。
- **是工作台，不只是一个窗口。** 视图向右或向下分栏，标签在窗格之间拖动，侧边面板可折成图标栏。亮暗两套主题。
- **录制与文件传输。** 勾上 `Record`，每次连接都把原始字节写进一个文件。通过 XMODEM、XMODEM-1K、YMODEM 或 ZMODEM 收发文件，设备端敲 `sz` / `rz` 会自动发起传输。
- **macOS、Windows、Linux。** 一套代码，各平台原生窗口，从 GitHub Releases 原地更新。

## 安装

[Releases](https://github.com/miskin-lee/serialX/releases) 页面提供预编译包：

| 平台 | 包 |
|---|---|
| macOS（Apple Silicon） | DMG |
| Windows（x86_64） | 安装程序，或便携版 ZIP |
| Linux（x86_64、ARM64） | DEB，或便携版 tar.gz |

安装包尚未经过 Apple 公证或 Windows 代码签名，首次启动时系统可能弹出安全提示。

serialX 启动后会在后台检查是否有更新的稳定版，并提示安装；`Help > Check for Updates…` 可随时手动检查。下载的安装包会与 Release 附带的 SHA-256 摘要核对，然后原地替换当前副本；选 `Relaunch` 立即切换，选 `Later` 则下次启动时生效。只读取公开的 Release 信息，不需要 GitHub 账号。

## 快速上手

1. **新建会话。** `Session > New Session…`、标签栏上的 `+`，或 `⌘N` / `Ctrl+N`。在列表里选设备（刚插上的话点 `Rescan`），选波特率和帧格式开关，对话框底部的摘要会实时显示当前选择，默认是 `115200 8N1`。
2. **起名、上色、归组。** `Tab` 字段给标签和保存的会话命名，留空则显示端口路径。24 种标签色任选，想归组就选一个分组。`Text` / `Hex` 决定日志以文本还是十六进制读取收到的内容。
3. **连接。** `Save & Connect`（或 `Enter`）把会话存进侧边面板并打开一个已连接的标签；`Connect` 只打开标签。每个标签有自己的连接和日志，标签上的圆点表示连接状态。
4. **和设备对话。** 点一下终端就能打字：普通按键、方向键、功能键和 `Ctrl` 组合键按终端的方式发送，设备的回显直接显示在屏幕上。也可以用侧边面板底部的发送栏：输入一行，`Enter` 发送，内容留在框里可以再发。

当前标签的连接 / 断开按钮在标题栏过滤框的右侧，旁边是这个会话的 `RX` 和 `TX` 字节计数。

## 终端

**能显示什么。** 颜色、粗体、下划线、反显、256 色和真彩色、宽字符、用 `\r` 重绘的行，全部按终端的方式渲染。在此之上，serialX 会给读日志时本来就会留意的部分上色：日志级别、时间、地址、路径、带单位的数字。设备自己输出的颜色始终优先。

**回滚。** 默认保留 50,000 行（可在设置里调到 100 到 1,000,000）。滚轮向上翻会暂停跟随输出，滚回底部恢复；右侧有滚动条。设备发来的 `clear` 和 `Session > Clear` 一样清屏。

**行号和时间戳。** 行号像编辑器一样从 1 开始，最旧的行被裁掉后剩下的行保持原号。时间戳是该行第一个字节到达的本地时间，精确到毫秒。清屏后行号重新从 1 开始。

**十六进制视图。** 以 `Hex` 创建的会话每行显示十六个字节，分两组，右侧用两根竖线夹着对应的字符。零值和边框灰色，可打印文本原色，行结束符绿色，其他控制字节品红，ASCII 以上的字节琥珀色。行随读取逐步填满，设备停顿时不满一行的字节立即显示。时间戳、行号、过滤、查找、选择和复制在十六进制日志里都能用。

**选择与剪贴板。** 拖动选取，双击选词，三击选整行，`Shift` 点击扩展选区。`⌘A` 全选，`⌘C` 复制并把被终端折行的内容拼回一行。`⌘V` 把剪贴板粘贴给设备，设备要求时使用括号粘贴。右键菜单有 `Copy`、`Copy with Timestamps`、`Paste` 和 `Select All`。

**只读标签。** 在会话对话框里取消勾选 `Interactive`，标签就不显示光标、不接收键入，发送只能通过发送栏或快捷发送。

## 过滤与查找

标题栏的**过滤框**边输入边筛选输出：默认按纯文本匹配，`.*` 切换正则表达式，`Aa` 区分大小写，右端实时显示“匹配行数 / 总行数”。默认在原位高亮匹配的行；点击划线眼睛开关进入遮罩模式，只显示整个回滚里匹配的行，并保留行号和时间戳以便看出间隔。写错的正则会标红，不会隐藏任何输出。`View > Filter Output…` 跳到过滤框，`Esc` 清空。

**查找**（`⌘F` / `Ctrl+F`）在终端右上角浮出一个查找栏，边输入边搜索整个回滚。匹配项染成琥珀色，当前项加上一圈并滚到屏幕中央，栏上显示“第 n 处 / 共 m 处”。`Enter` 下一处，`⇧Enter` 上一处，`Aa` 和 `.*` 与过滤框相同，`Esc` 关闭。有选中文字时，`⌘F` 直接以选中的文字查找。遮罩开着时，查找只在遮罩显示的行里进行。

## 会话与快捷发送

侧边面板存放你在多次运行之间要复用的东西。

**会话。** 保存的会话是一张张卡片，带标签色和名字，端口和参数在提示里。双击打开：设备在线就立即连接，该端口已有标签则切过去。铅笔编辑，垃圾桶删除（先询问）。会话可以归入分组：区块标题上的文件夹按钮新建分组，分组可折叠、改名、删除（删除分组时会话保留）。`⌘S` / `Ctrl+S` 保存当前会话。

**快捷发送。** 保存的命令就是一个按钮，点一下就发到当前标签。保存时可以起名和归组；区块顶部的搜索框按名字或内容筛选。面板底部的发送栏是命令的起点：输入内容，选 `UTF-8` 或 `HEX`（`41 54 0D 0A` 会发送四个字节；不合法的 hex 会把卡片描红且不发送），在 `↵` 下拉框里选行结束符（`CRLF`、`LF` 或 `None`），点 `To` 行末尾的 `Save` 保存。`To` 行同时显示发送目标会话和它的连接状态。

**折叠面板。** 点击区块标题折叠该区块。`⌘B` / `Ctrl+B` 或标题栏右端的开关把整个面板折成带计数角标的图标栏。拖动面板左边缘调整宽度。

## 布局与主题

`⌘\` / `Ctrl+\` 把当前会话放进旁边一个独立窗格，`⌘⇧\` / `Ctrl+Shift+\` 放到下面，最多三个窗格。`View` 菜单、标签右键菜单和标题栏右端的开关都有同样的操作；`Join Split` 把窗格合回去。拖动窗格之间的分隔线调整大小，把标签拖到另一个窗格的标签栏或日志上就把会话搬过去。窗格随最后一个标签关闭。

两套主题，纯白和近黑，默认暗色：`View > Theme`，或 `⌘⇧L` / `Ctrl+Shift+L`。

## 录制

在会话对话框里勾上 `Record`，每次连接都会写一个独立文件，内容是端口读到的原始字节，可以回放或比对。文件以会话名和连接时间命名，按日期归档：

```
~/Documents/serialX/2026-09-09/Motor board-20260909-142312.log
```

存放文件夹在设置里选择，录制文件在所选文件夹下保持自己的 `serialX` 目录结构。连接打开时日志会说明文件写到了哪里，标签提示会显示正在录制，断开连接时关闭文件。

## 文件传输

`Session > Send File…` 和 `Session > Receive File…` 打开同一个对话框：先选协议（`XMODEM`、`XMODEM-1K`、`YMODEM` 或 `ZMODEM`，开关下方一行说明当前选择的含义），再选要发送的文件或接收到的文件夹。XMODEM 不携带文件名，所以用它接收时要输入一个名字。

传输进行时，日志顶部有一条状态带：方向、文件名、协议、带字节数和速率的进度条，以及 `Cancel`。传输期间端口归传输独占，结束后日志会说明结果：文件及其大小和耗时，或者中断的原因。

设备发起时 ZMODEM 不需要对话框：在设备的 shell 里敲 `sz` 会自动开始接收，存到接收对话框上次用的文件夹（未选过则是 `Downloads`）；敲 `rz` 会打开发送对话框并选中 ZMODEM。收到的文件沿用发送方给的名字，重名时加编号，并且始终写在所选文件夹内。

## 设置

`⌘,` / `Ctrl+,` 打开设置：回滚行数、终端字号（8 到 32 pt，左侧栏跟随）、录制文件存放的文件夹。设置对所有会话同时生效，并随工作区保存。

serialX 不内置字体。终端使用平台的编辑器字体（macOS 上是 Menlo，Windows 上是 Consolas，Linux 上是 Droid Sans Mono），界面使用系统 UI 字体，设备发来的中日韩文字回退到系统自带的 CJK 字体，并优先使用你的系统语言。

## 快捷键

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 新建会话 | `⌘N` | `Ctrl+N` |
| 保存会话 | `⌘S` | `Ctrl+S` |
| 关闭会话 | `⌘W` | `Ctrl+W` |
| 连接 / 断开 | `⌘⇧C` | `Ctrl+Shift+C` |
| 重新扫描端口 | `⌘R` | `Ctrl+R` |
| 暂停 / 恢复接收 | `⌘⇧P` | `Ctrl+Shift+P` |
| 清空终端 | `⌘K` | `Ctrl+K` |
| 全选日志 | `⌘A` | `Ctrl+Alt+A` |
| 复制选区 | `⌘C` | `Ctrl+Insert`（有选区时 `Ctrl+C` 也复制） |
| 粘贴给设备 | `⌘V` | `Ctrl+Shift+V` 或 `Shift+Insert` |
| 查找 / 下一处 / 上一处 | `⌘F` / `⌘G` / `⌘⇧G` | `Ctrl+F` / `F3` / `Shift+F3` |
| 发送栏 `UTF-8` / `HEX` | `⌘⇧H` | `Ctrl+Shift+H` |
| 自动滚动 | `⌘⇧A` | `Ctrl+Shift+A` |
| 上一个 / 下一个标签 | `⌘⇧[` / `⌘⇧]` | `Ctrl+PageUp` / `Ctrl+PageDown` |
| 向右分栏 / 向下分栏 | `⌘\` / `⌘⇧\` | `Ctrl+\` / `Ctrl+Shift+\` |
| 侧边面板 | `⌘B` | `Ctrl+B` |
| 亮 / 暗主题 | `⌘⇧L` | `Ctrl+Shift+L` |
| 设置 | `⌘,` | `Ctrl+,` |
| 发送发送栏里的内容 | `Enter` | `Enter` |

Windows 和 Linux 上 `Ctrl+A` 和 `Ctrl+C` 本身像在终端里一样发给设备，只有存在选区时 `Ctrl+C` 才是复制。`Esc` 关闭查找栏或清空过滤。

## 从源码构建

```bash
cargo run
```

建议使用最新稳定版 Rust。首次构建需要下载 GPUI 相关依赖，耗时较长；macOS 还需要安装 Xcode 或 Command Line Tools。
